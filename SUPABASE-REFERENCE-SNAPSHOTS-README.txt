SUPABASE PREVIEW REFERENCE SNAPSHOTS

1. In Supabase SQL Editor, run:
   SUPABASE-project-reference-documents.sql

2. Deploy the updated website.

3. Sign in and save a project.

4. Open:
   catalog/website-preview.html

5. Press:
   Save Reference Snapshot

Each save creates a new version in:
public.project_reference_documents

The database stores:
- rendered preview HTML
- complete selection JSON
- theme
- design system
- Header/Hero editor settings
- Navigation editor settings
- skipped steps
- completion percentage
- version number
- timestamps

This gives you a frozen reference of what the customer approved/selected even if the live project is edited later.
